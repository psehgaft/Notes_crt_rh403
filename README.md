# Notes_crt_rh403

Study and exam notes for the Red Hat **RH403** course — commands, configuration snippets and practical examples, organized by topic following the same layout as the other `Notes_crt_*` repos in this profile.

## Lab setup

```sh
# register and prepare a lab node
sudo subscription-manager register
sudo subscription-manager attach --auto
```

## Topics

- Installation and environment setup
- Core RH403 concepts and administration tasks
- Practice commands
- Exam tips

## Usage

Copy any command block into a lab terminal; placeholders such as `[domain]` or `[path]` must be replaced with values from your own environment.

## Notes

These are personal study notes — commands are shorthand for lab practice, not production runbooks.
